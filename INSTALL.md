# CI360 Degrees theme — final installable build (v2.6.1)

This ZIP is a complete Hello Elementor child theme, not a patch.

## Install

1. Install the free **Hello Elementor** parent theme and keep it installed.
2. Install and activate **Elementor**. Elementor Pro is optional.
3. Install **Secure Custom Fields** or **ACF Pro** for the editable CI360 fields.
4. In WordPress go to **Appearance → Themes → Add New → Upload Theme**, upload this ZIP, and activate **CI360 Degrees – Hello Elementor Child**.
5. Go to **Appearance → CI360 Setup** and import the content library. The starter-page/menu build is optional and remains unticked by default.
6. Use **Appearance → CI360 Editing Guide** for the edit locations.

## Editable areas

- Header logo and CTA: **CI360 Settings → Header & menu**.
- Header / overlay / footer / legal links: **Appearance → Menus**.
- Conditional footer variants: **Footers**.
- Services hero and card layout: edit the Services page in Elementor and select the CI360 Services widgets.
- Insights cinematic hero/archive: edit the Insights page in Elementor and select **Insights – Editorial Archive**.
- About timeline: edit **About – Timeline** in Elementor.

The theme includes its CSS, JavaScript, demo data, bundled images, PHP templates, Elementor widgets and page templates.
